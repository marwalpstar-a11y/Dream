# DREAMEXCH24 - Sportswear E-Commerce & Sports Exchange Platform

Redesign of [dreamexchwork.live](https://dreamexchwork.live/) into a premium, modern, and visually attractive Sportswear E-Commerce & Sports Exchange liaison website with full mobile app responsiveness (PWA).

## 🚀 Features

- **100% Content Integrity:** All original headlines, disclaimers, numbers, and operational information strictly preserved.
- **Athletic Sportswear Visuals:** Bold dark carbon theme with Volt Gold (`#FACC15`) and WhatsApp Emerald (`#25D366`) accents.
- **Configurable WhatsApp Integration:** Primary WhatsApp ID CTA linked to `9549376324`.
- **Mobile-First Responsive Layout:** Includes mobile bottom app bar, offcanvas drawer, and PWA manifest.
- **Pages Included:**
  - `index.html` - Home (Hero, Key Metrics, Operational Standards, 3-Step Setup Flow, Disclaimers)
  - `services.html` - Services & IDs
  - `shop.html` - Shop Catalog with Interactive Categories & Sorting
  - `cricket-id.html` - Cricket Exchange ID
  - `t20-id.html` - T20 Franchise Tournament Desk
  - `football-id.html` - European Leagues & ISL Market Access
  - `product-detail.html` - Product Showcase & Format Selector
  - `about.html` - Operational Framework & Human Verification
  - `contact.html` - Direct Operator Desk & Query Submission
  - `responsible-gaming.html` - Strict 18+ Verification & Compliance Rules

## 💻 Local Preview
Double-click `Start-Website.bat` to launch the local web server on `http://localhost:8080/`.
